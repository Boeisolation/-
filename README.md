# 牛熊位置监测台

**Condition / Trigger 双层框架** — 每周手动打一次分，自动判断你落在四宫格的哪格。

> 这是**风控姿态工具，不是择时神器**。条件红灯只代表"该保守"，真正动手要等扳机翻转。

---

## 功能

- 支持美股 / 日经 / 恒生三市场，指标描述自动切换
- 8 项指标分两层：**条件层**（慢变量，定姿态）+ **扳机层**（快变量，定时点）
- 四象限图实时可视化当前位置：贵但仍在趋势 / 风险兑现 / 低风险正常 / 健康回调
- 每周快照保存到浏览器本地（`localStorage`），折线图展示历史趋势
- 纯前端单文件，无后端、无登录、无外部 API

## 使用方法

直接在浏览器打开 `main.html`，无需任何构建步骤。

每周操作：
1. 切换目标市场（美股 / 日经 / 恒生）
2. 逐项填写当周读数（可选），选择红 / 黄 / 绿灯
3. 看右侧四象限图判断当前位置
4. 点击「保存本周快照」留痕

## 四象限逻辑

|  | 扳机安静 | 扳机活跃 |
|--|---------|---------|
| **条件偏热（≥2 红）** | 贵但仍在趋势中<br>→ 持有，停加杠杆 | ⚠ 风险兑现<br>→ 按预设规则减仓 |
| **条件偏冷（＜2 红）** | 低风险 / 正常<br>→ 维持 | 健康回调 / 噪声<br>→ 维持 |

## 三条铁律

1. 阈值是"区间"不是"线"
2. 持续性 > 单周读数（连续 2–3 周极端才算数）
3. 单一绿灯别加杠杆，单一红灯别清仓
